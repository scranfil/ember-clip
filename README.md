# Ember Clip

**Premium magnetic cigar holder** for golfers, boaters, grill masters, and outdoor enthusiasts.

Live site: [View Landing Page](index.html)

## Features

- Strong neodymium magnets (holds up to 5 lbs)
- Soft-grip adjustable clamp for cigars up to 60+ ring gauge
- Weather-resistant 3D printed construction
- Signature vibrant blue finish

## Interactive 360° Product Viewer

This landing page includes a custom-built 360° product rotator (`360-viewer.js`) using real product photography with clean backgrounds.

- Drag left/right to rotate
- Autoplay support
- Touch-friendly
- 8 angles captured

## Getting Started

Just open `index.html` in any modern browser. No build step required.

## Tech Stack

- Vanilla HTML + Tailwind CSS (via CDN)
- Font Awesome 6
- Custom vanilla JavaScript 360° viewer (no dependencies)
